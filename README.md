# decent.clothing

The static redirect from [decent.clothing](https://decent.clothing) to
[decentsoftwear.com](https://decentsoftwear.com/).

The complete article site and its history are preserved in
[`Decent-Software-LLC/decent.clothing-dev`](https://github.com/Decent-Software-LLC/decent.clothing-dev)
and served at [dev.decent.clothing](https://dev.decent.clothing).

Both the homepage and custom 404 page redirect to the new website. This site
is dependency-free and can be served by any static web server.
